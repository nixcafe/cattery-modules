    Modules

    cattery defines 261 module files under the cattery namespace. The count includes room profiles and secrets companion modules. Enable modules individually or use a room. The tables below list the modules and their main options. See the module source for the full option set.

    Theming

    cattery.desktop.addons.catppuccin

    Catppuccin theming for the desktop environment. The module exists in the NixOS and home-manager sets.

    cattery.desktop.addons.catppuccin.enable = true;
    OptionDescription
    enableEnable Catppuccin
    autoEnableEnable all Catppuccin integrations by default. Defaults to the value of enable
    extraOptionsExtra options merged into the Catppuccin configuration

    User

    cattery.user

    Core user configuration. Many modules read these values for defaults.

    OptionTypeDescription
    namestrUser name
    realNamenull or strFull name, used for the Git user name
    email.addressnull or strEmail address
    email.userNamenull or strMail account user name, defaults to email.address
    email.imapnull or submoduleIMAP settings with host and port
    email.smtpnull or submoduleSMTP settings with host and port
    defaultUserShellnull or path or packageLogin shell, for example pkgs.fish. The matching shell module enables by default
    gpg.signKeynull or strGPG signing key
    gpg.encryptKeynull or strGPG encryption key
    initialHashedPasswordnull or strInitial user password hash
    useSecretPasswordFileboolRead the password from an agenix secret
    authorizedKeys.keyslist of strSSH authorized keys
    authorizedKeys.keyFileslist of pathFiles containing SSH authorized keys
    settingsattrsExtra values consumed by theme and desktop modules
    homenull or strHome directory (read-only)
    uidnull or intUser ID (read-only)
    gidnull or intGroup ID (read-only)
